# Checklist triển khai HoaAn ERP

Trang checklist dùng chung cho các phòng ban. Ai mở [https://checklist-erp.vercel.app](https://checklist-erp.vercel.app) cũng thấy cùng trạng thái tick.

## Chạy local

```bash
python3 -m http.server 4173
```

Local chỉ xem giao diện. Lưu dùng chung chạy trên Vercel (`/api/state`).
